# 003 - fix - 避免 initial_prompt 和空音频幻觉被粘贴

- 状态：done
- 日期：2026-05-31

## 背景

用户反馈偶发识别出“点点关注”一类无关内容，且会把
“请根据语气正确使用逗号、句号、问号、感叹号等标点符号”这类提示词本身识别出来。

## 原因

`faster-whisper` 的 `initial_prompt` 是转写上下文，不是指令提示词。把“请根据……”这种命令句放进去后，
在静音、弱语音或不确定音频下，模型可能把这段上下文当成真实语音内容续写出来。

“点点关注”“谢谢观看”等通常是 Whisper 在空音频、背景噪声或尾部静音里的常见幻觉。

## 处理

- 默认关闭 `initial_prompt`，避免提示词泄漏到识别结果。
- 加载历史配置时，如果发现旧版默认指令句，自动按空提示处理。
- 增加 `hotwords` 配置，用于提示 `GitHub`、`OpenAI`、`systemd` 等中英混说技术词。
- 转写时设置 `condition_on_previous_text=False`，降低短语音输入场景里的上下文续写倾向。
- 增加窄范围输出过滤：仅当整段文本明显是旧提示词泄漏，或精确等于常见空音频幻觉短句时，视为没有识别到文本。
