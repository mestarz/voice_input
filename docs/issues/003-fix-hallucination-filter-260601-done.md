# 003 - fix - 过滤 Whisper 空音频幻觉短语

- 状态：done
- 日期：2026-06-01

## 背景

用户反馈识别出 “请不吝点赞 订阅 转发 打赏支持明镜与点点栏目”。

这是 Whisper 的经典幻觉：训练数据中混入大量自媒体/搬运视频的固定结尾字幕，
模型将“无有效语音内容”（静音、底噪、VAD 漏切的极短空白段）与该高频文本强关联。
当输入缺乏声学信息时，decoder 回退到语言先验，吐出这类训练中高频字幕。

`transcriber.py` 原有的 `_looks_like_hallucination` 仅精确匹配 6 个短语
（点点关注、谢谢观看等），未覆盖“点赞订阅转发打赏/明镜/点点栏目”这一族，导致漏网。

## 实现逻辑

- `transcriber.py`：新增 `_HALLUCINATION_SUBSTRINGS` 子串列表
  （如 `请不吝点赞`、`点赞订阅转发打赏`、`打赏支持明镜`、`明镜与点点栏目`、`字幕由` 等）。
- `_looks_like_hallucination()`：在归一化文本上做子串匹配，命中任一即判为幻觉，
  `transcribe()` 返回空串。子串匹配比精确匹配更稳，可覆盖该幻觉的多种变体。

## 说明

- 归一化会去除空格与标点后再匹配。
- 已通过本地验证：该幻觉句与“谢谢观看”被过滤，正常语句不受影响。
- 修改后需重启 systemd 用户服务 `voice-paste.service` 才能加载新代码。
