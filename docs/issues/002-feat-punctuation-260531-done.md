# 002 - feat - 识别结果标点支持

- 状态：done
- 日期：2026-05-31

## 背景

用户反馈语音识别结果没有标点符号。Whisper large-v3 本身支持标点输出，
中文场景下不出标点的常见原因是缺少引导提示（initial_prompt）。

## 实现逻辑

- `config.py`：新增 `initial_prompt` 配置项，默认提供一段带标点的中文引导语，
  明确要求按语气使用逗号、句号、问号、感叹号等标点符号。设为空字符串可关闭。
- `transcriber.py`：`transcribe()` 将 `initial_prompt` 传入
  `WhisperModel.transcribe()`，引导模型输出标点风格。

## 说明

- 标点由 Whisper 依据语气/停顿推断，较长且有自然停顿的语句效果更明显。
- 中文模型对问号/感叹号本就较少输出，故引导语显式列举这些标点以增强倾向。
- 全程本地，不依赖云服务。
